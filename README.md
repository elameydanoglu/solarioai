# SolarioAI

Predicts solar radiation in Istanbul for any future date and hour. Two Random Forest models (daily total + hourly profile), trained on Open-Meteo historical data 2015–2025, run directly in the browser.

Team SYZYGY: Azra Tüfekçi, Ela Naz Meydanoğlu, Zehra Kalkavan.

The `Daily forecast refresh` workflow pulls the latest measured weather every evening so the "tomorrow" forecast stays current.
